# پایپ‌لاین خبر AI با GitHub Actions (بدون سرور، بدون Docker)

## ساختار
```
ai-news-github/
├── .github/workflows/news_pipeline.yml   # زمان‌بندی و اجرای خودکار
├── pipeline/
│   ├── main.py            # منطق اصلی: خبر -> فیلتر -> ویدیو -> تلگرام
│   ├── generate_video.py  # ساخت ویدیو از متن
│   └── requirements.txt
└── .gitignore
```

## مرحله ۱: ساخت ریپازیتوری روی GitHub
1. یک اکانت GitHub بساز (اگه نداری) در github.com — فقط ایمیل لازمه
2. یک ریپازیتوری جدید بساز، **حتماً Public** کن (برای اجرای رایگان و نامحدود Actions)
3. تمام فایل‌های این پوشه رو داخل همون ریپازیتوری آپلود کن (می‌تونی از رابط وب GitHub با "Upload files" همین کار رو بکنی، نیازی به git command line نیست)

## مرحله ۲: اضافه کردن کلیدها (Secrets)
داخل ریپو برو به:
`Settings -> Secrets and variables -> Actions -> New repository secret`

سه‌تا Secret بساز:
- `GEMINI_API_KEY` — از aistudio.google.com
- `TELEGRAM_BOT_TOKEN` — توکن باتی که با BotFather ساختی
- `TELEGRAM_CHAT_ID` — همون Chat ID که قبلاً گرفتی

## مرحله ۳: تست دستی (بدون نیاز به صبر کردن تا زمان‌بندی)
1. برو به تب **Actions** بالای صفحه ریپو
2. روی workflow با اسم **"AI News Pipeline"** کلیک کن
3. دکمه **"Run workflow"** رو بزن (سمت راست)
4. چند دقیقه صبر کن، روی اجرای در حال انجام کلیک کن تا لاگ زنده رو ببینی

اگه موفق بود، باید ویدیوها مستقیم توی تلگرامت برسن.

## مرحله ۴: فعال‌سازی خودکار
هیچ کاری لازم نیست! همین که فایل `news_pipeline.yml` توی ریپو باشه، GitHub خودش طبق `cron: "0 */6 * * *"` هر ۶ ساعت یک‌بار خودکار اجرا می‌کنه — چه سیستم تو روشن باشه چه نه، چه نت داشته باشی چه نه.

## نکات مهم

1. **این نسخه دیگه به Docker/n8n نیازی نداره.**
2. **حداکثر ۳ ویدیو در هر اجرا** — برای تغییرش، مقدار `MAX_ITEMS` رو در فایل workflow عوض کن.
3. **فایل `seen_links.json`** خودکار توی ریپو ذخیره و آپدیت می‌شه تا خبر تکراری دوباره پردازش نشه.
4. **زمان‌بندی رو می‌تونی عوض کنی:** در فایل `news_pipeline.yml"`، خط `cron: "0 */6 * * *"` رو ویرایش کن (مثلاً `0 */2 * * *` برای هر ۲ ساعت).
5. **اگه یک اجرا خطا داد**، لاگش توی تب Actions قابل مشاهده‌ست — می‌تونی متنش رو کپی و برام بفرستی تا کمک کنم.

## اگه چند هفته دسترسی نداری
هیچ کاری لازم نیست بکنی. GitHub خودش طبق زمان‌بندی اجرا می‌کنه و ویدیوها رو به تلگرامت می‌فرسته. وقتی برگردی، فقط تاریخچه پیام‌های تلگرام رو چک کن.
